nomenclaturas mais usadas para branchs

modificacoes e novas funcionalidades
    feat ou feature/descricao-da-modificacao

correção de problema
    fix ou bugfix/descricao-do-problema

modificacao urgente na main 
    hotfix/descricao-do-problema

git branch
    mostra branchs criadas 

git branch -m nomeDaBranch 
    altera nome da branch 

git branch checkout nomeDaBranch
    entra na branch
